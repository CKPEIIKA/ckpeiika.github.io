# Open Sans

Version: Fontsource package `@fontsource/open-sans@5.2.5`.

Included subsets: Latin, Cyrillic, Greek, and Greek Extended, in normal weights
400 and 700. The browser downloads only the subset and weight required by the
current page because each face declares its Unicode range.
