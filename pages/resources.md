## OpenFOAM

- [OpenFOAM Foundation (.org)](https://openfoam.org/) — официальный сайт ветки Foundation.
- [Об OpenFOAM (CFD Direct)](https://cfd.direct/openfoam/about/) — кто разрабатывает и распространяет OpenFOAM Foundation.
- [OpenCFD / OpenFOAM.com](https://www.openfoam.com/) — официальный сайт ветки OpenCFD.
- [История OpenCFD](https://www.openfoam.com/news/history) — официальная хронология ветки OpenCFD.
- [Обзор документации OpenFOAM](https://www.openfoam.com/documentation/overview) — устройство пакета, руководства и справочные материалы.
- [Репозиторий разработки OpenFOAM-dev](https://github.com/OpenFOAM/OpenFOAM-dev) — исходный код и материалы разработки OpenFOAM Foundation.
- [Вики-сообщество OpenFOAM](https://wiki.openfoam.com/)
  Туториалы, учебные кейсы, расширения и статьи.
- [Верификация и валидация в OpenFOAM](https://www.openfoam.com/documentation/guides/latest/doc/guide-verification-validation.html)
  Руководство по проверке сеточной сходимости и достоверности расчёта.
- [Основы C++ для OpenFOAM (Håkan Nilsson)](https://wiki.openfoam.com/Basics_of_C%2B%2B_by_Hakan_Nilsson) — база для написания собственных решателей.
- [Серия «3 недели» по OpenFOAM](https://wiki.openfoam.com/%223_weeks%22_series) — интенсивный вводный курс.
- [Curiosity Fluids](https://curiosityfluids.com/) — практические кейсы и обучающие материалы.
- [Уроки Wolf Dynamics](http://www.wolfdynamics.com/index.php) — пошаговые материалы по OpenFOAM.
- [OpenFOAM: Jozsef Nagy (YouTube)](https://www.youtube.com/@OpenFOAMJozsefNagy) — видео о настройке и расчёте задач OpenFOAM.

> 📝 Примечание о форках OpenFOAM  
> Сейчас фактически существуют две официально поддерживаемые ветки экосистемы:  
> **OpenFOAM Foundation / CFD Direct**: [openfoam.org](https://openfoam.org/), [cfd.direct/openfoam/about](https://cfd.direct/openfoam/about/)  
> **OpenCFD / OpenFOAM Ltd**: [openfoam.com](https://www.openfoam.com/), [openfoam.com/news/history](https://www.openfoam.com/news/history)  
> [Почему так?](https://www.cfd-online.com/Forums/openfoam/197150-openfoam-com-versus-openfoam-org-version-use.html).

## CFD

- [CFD Online](https://www.cfd-online.com/) — форумы, статьи, обсуждения.
- [Обучающие статьи по CFD](https://cfd-training.com/articles-2/) — короткие материалы по численным методам и постановке задач.
- [Holzmann CFD](https://holzmann-cfd.com/) — теория и практика CFD.
- [Курсы CFD (Chalmers)](https://www.tfd.chalmers.se/~hani/kurser/OS_CFD/) — университетские лекции и упражнения.
- [Milovan Perić CFD (YouTube)](https://www.youtube.com/@MilovanPericCFD/videos) — численные методы и физическая интерпретация.
- [Блог CFD-ZJW](http://cfd-zjw.blogspot.com/) — практические примеры по CFD.
- [Полный путь изучения CFD](https://jahid-hasan.com/writings/a-complete-learning-path-for-cfd/) — последовательный план изучения дисциплины.
- [Метод характеристик](https://kyleniemeyer.github.io/gas-dynamics-notes/compressible-flows/method-characteristics/) — раздел заметок по газовой динамике.
- [Pipe Flow Verification (Barba Group)](https://github.com/barbagroup/pipe_verification/tree/main) — верификация численных схем.
- [Архив Capella CFD](https://web.archive.org/web/20060208175919/http://capella.colorado.edu/~laney/otherbooks.htm) — архив классических книг по CFD, в том числе материалов J. Laney.

## Машинное обучение и CFD

- [Литература по машинному обучению для CFD](https://github.com/AndreWeiner/machine-learning-applied-to-cfd/blob/master/literature.md) — обзор методов и публикаций.
- [TensorFlowFoam](https://github.com/argonne-lcf/TensorFlowFoam) — исторический пример интеграции машинного обучения в OpenFOAM 5 через TensorFlow 1.15.
- [PythonFOAM](https://github.com/argonne-lcf/PythonFOAM) — связка Python и OpenFOAM.
- [DEGANN](https://github.com/Krekep/degann) — машинное обучение для дифференциальных уравнений.
- [Численные туры (Peyré)](https://nbviewer.org/github/gpeyre/numerical-tours/tree/master/python/) — численные методы, оптимизация и машинное обучение.
- [CS231n: оптимизация](https://cs231n.github.io/optimization-2/) — градиентные методы и обучение моделей.
- [Understanding Deep Learning](https://udlbook.github.io/udlbook/) — книга об основных методах глубокого обучения.
- [RLHF Book](https://rlhfbook.com/) — техническое введение в обучение с обратной связью от человека.
- [ОДУ и СДУ для машинного обучения](https://rbcborealis.com/research-blogs/odes-and-sdes-for-machine-learning/) — связь дифференциальных уравнений и методов обучения.
- [Список ресурсов по ИИ для CFD](https://github.com/WillDreamer/Awesome-AI4CFD)
  Статьи, исходный код и наборы данных по машинному обучению в CFD.
- [PhysicsNeMo от NVIDIA](https://developer.nvidia.com/physicsnemo)
  Физически информированное машинное обучение, PINN, нейронные операторы и ускорение CFD на GPU.
- [DeepXDE](https://github.com/lululxvi/deepxde)  
  Библиотека PINN для решения дифференциальных уравнений и задач CFD.
- [PhiFlow](https://github.com/tum-pbs/PhiFlow)  
  Дифференцируемая библиотека для моделирования уравнений в частных производных.

- [Машинное обучение в механике жидкости](https://www.annualreviews.org/content/journals/10.1146/annurev-fluid-010719-060214) — обзор применения машинного обучения для анализа, моделирования, оптимизации и управления течениями.
- [Data-Driven Science and Engineering](https://www.databookuw.com/) — динамические системы, управление, POD, DMD и модели пониженного порядка.
- [MIT 6.S191: введение в глубокое обучение](https://introtodeeplearning.com/) — практический вводный курс с ноутбуками.
- [fast.ai](https://www.fast.ai/) — практические курсы по глубокому обучению.
- [PySINDy](https://pysindy.readthedocs.io/en/stable/) — разреженное восстановление нелинейных динамических систем.
- [PyDMD](https://pydmd.github.io/PyDMD/) — разложение по динамическим модам с примерами и ноутбуками.
- [PyKoopman](https://github.com/dynamicslab/pykoopman) — приближение оператора Купмана и моделирование динамики по данным.

## Высокоскоростные потоки

- [hy2Foam](https://hystrath.github.io/solvers/fleming/hy2foam/)  
  Гиперзвуковой солвер на базе OpenFOAM: 2T-модели, химия, MHD.
- [Eilmer (University of Queensland)](https://github.com/gdtk-uq/gdtk)  
  Реальный газ, гиперзвуковые течения, ударные трубы и сопряжённый теплообмен.
- [SU2](https://su2code.github.io/)  
  Решатель для задач аэродинамики и термохимического неравновесия.
- [Документация SU2 v7](https://su2code.github.io/docs_v7/Guide-to-v7/)
  Описание изменений, настройки расчёта и перехода на версию 7.
- [SU2 NEMO: термохимическое неравновесие](https://su2code.github.io/docs_v7/Thermochemical-Nonequilibrium/) — описание решателей SU2 для неравновесных течений.
- [hyStrath](https://github.com/hystrath/hyStrath) — исходный стек для гиперзвуковых реагирующих течений.
- [Mutation++](https://github.com/mutationpp/Mutationpp) — библиотека термодинамики, транспорта и химии ионизированных газов.
- [Руководство пользователя Eilmer](https://gdtk.uqcloud.net/docs/eilmer/user-guide/) — постановка задач и запуск расчётов в Eilmer.
- [COOLFluiD](https://andrealani.github.io/COOLFluiD/)  
  Платформа высокопроизводительных расчётов для CFD и мультифизики.
- [COREFL-CPC](https://github.com/Liangerty/COREFL-CPC) — решатель на GPU с использованием CUDA.
- [Книга Clawpack о задаче Римана](http://www.clawpack.org/riemann_book/) — теория и примеры на Python.
