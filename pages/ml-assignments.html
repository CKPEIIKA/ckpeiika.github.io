Задача 0 — ознакомительная работа

Общая для всех студентов

Цель работы — познакомиться с агентным рабочим процессом до начала индивидуальных исследовательских заданий.

Практическое задание

  1. Клонировать с GitHub небольшой учебный проект по физике или машинному обучению.
  2. Попросить агента только исследовать структуру проекта: основные файлы, зависимости, точки входа, способ запуска и тестирования. На этом этапе агент не должен изменять код.
  3. Попросить агента провести аудит научной корректности: проверить физические предположения, размерности и единицы, формулы, используемые модели, обработку данных и наличие очевидных методических ошибок.
  4. При помощи агента создать собственный небольшой проект по шаблону, описанному ранее в курсе: с понятной структурой, воспроизводимым запуском, зависимостями, проверками и краткой документацией.

Минимальный результат

Итогом работы должен быть один файл .md, в котором кратко зафиксированы: выбранный исходный проект, его структура, основные замечания научного аудита, а также описание созданного собственного проекта и способа его запуска.

Присылать этот файл преподавателю отдельно не требуется. Он нужен как рабочий результат ознакомительной работы и как подтверждение того, что студент умеет использовать агента для исследования, проверки и создания проекта.

Условия задач

Линейная модель: \(\hat{y}=\beta_0+\sum_j\beta_j\phi_j(x)\)

Общие требования к моделям
  1. Итоговая модель должна быть линейной по оцениваемым коэффициентам: ŷ=β₀+Σⱼβⱼφⱼ(x). Нелинейность допускается в преобразованных признаках φⱼ(x).
  2. Обязательны: базовая модель, метод наименьших квадратов (МНК), физически мотивированные преобразования признаков и полиномиальные признаки второй степени. Третью степень использовать только при достаточном объёме данных и подтверждённом улучшении по кросс-валидации.
  3. Обязательны гребневая регрессия (Ridge) и по крайней мере один метод с L1-регуляризацией: лассо-регрессия (Lasso) или Elastic Net; желательно сравнить все три.
  4. Перед регуляризацией признаки стандартизировать. Стандартизация, кодирование категорий, построение полиномиальных признаков и любой отбор признаков должны выполняться внутри конвейера обучения, отдельно для каждого разбиения кросс-валидации.
  5. Степень полинома и коэффициенты регуляризации выбирать только по обучающей части данных с кросс-валидацией. Тестовую выборку не использовать ни для подбора признаков, ни для настройки модели.
Аэроакустика профиля · вариант 1

Набор данных: UCI / NASA Airfoil Self-Noise

Постройте эмпирическую модель уровня аэродинамического шума профиля NACA 0012 по частоте, углу атаки, хорде, скорости набегающего потока и толщине вытеснения пограничного слоя.

Проверка модели

Помимо обычной кросс-валидации полностью отложить один диапазон скорости потока или угла атаки и проверить перенос модели.

Исследовательский вопрос

Выделить хотя бы одну устойчивую зависимость уровня шума от режима обтекания и показать область, где выбранная линейная по коэффициентам модель систематически ошибается.

Что включить в работу

  1. Описать происхождение набора данных, физический смысл целевой величины и входных переменных, указать единицы измерения и до обучения сформулировать не менее двух проверяемых физических гипотез.
  2. Построить простую базовую модель и модель МНК. Затем сравнить их с физически мотивированной линейной постановкой, полиномиальной регрессией и регуляризованными линейными моделями.
  3. Привести MAE, RMSE и R² для обучающей, кросс-валидационной и тестовой оценок; показать зависимость ошибки проверки от сложности модели или силы регуляризации и указать признаки недообучения либо переобучения.
  4. Построить график «измеренное — предсказанное» и график остатков; проверить, нет ли в остатках систематической зависимости от прогноза или ключевого физического параметра.
  5. Оценить устойчивость важных коэффициентов с помощью повторной кросс-валидации или бутстрэп-процедуры: знак, порядок величины, чувствительность к коррелированным признакам.
  6. Выполнить предусмотренную для варианта проверку на отложенном физическом режиме, объекте, временном интервале или диапазоне параметров и сравнить её с обычной интерполяционной оценкой.

Признаки

Рассмотреть log f, log U, степени U, а также физически осмысленные комбинации, например безразмерную частоту f·c/U. Полиномиальные признаки строить только после выбора разумного базового набора.

Сопротивление корпуса яхты · вариант 2

Набор данных: UCI Yacht Hydrodynamics

Исследуйте зависимость безразмерного остаточного сопротивления корпуса яхты от пяти геометрических коэффициентов и числа Фруда.

Проверка модели

Строки с одинаковыми пятью геометрическими параметрами считать одной формой корпуса. Несколько форм корпуса полностью исключить из обучения; отдельно проверить крайний диапазон числа Фруда.

Исследовательский вопрос

  6. Выполнить предусмотренную для варианта проверку на отложенном физическом режиме, объекте, временном интервале или диапазоне параметров и сравнить её с обычной интерполяционной оценкой.

Признаки

Использовать исходные признаки и только лаги 1, 2 и 3 шага для температуры помещения, наружной температуры и солнечного излучения. Большой набор авторегрессионных признаков не строить.
