# Бинарное столкновение: приложение и физическая модель

27 шагов в 9 разделах; приложение на русском языке. Откройте через HTTP из корня репозитория: `python3 -m http.server 8000 --bind 127.0.0.1`, затем `/demos/binary-collision/`. Автономный HTML находится в поставочном архиве.

## Обозначения

`r = r1 − r2`, `g = v1 − v2`, `μ = m1 m2/(m1+m2)`. Входящая относительная скорость направлена вдоль +x. Прицельный параметр b неотрицателен; входящее смещение лежит в плоскости yz. Азимут φ отсчитывается от +y к +z вокруг +x.

Для гладких потенциалов используются приведённые единицы `ℓ0 = ε = μ = 1`, энергия на бесконечности `E = g²/2`. В плоском расчёте `Lz = −gb`, поэтому формула `L = μgb` в объяснении относится к модулю момента.

Наблюдаемый полярный угол `χ = acos(cos Θ)` лежит в `[0,π]`. Знаковая развёрнутая функция отклонения Θ может быть отрицательной и проходить несколько оборотов. Геометрическая формула выходного направления с положительным `sin χ` показывается в разделах HS; динамическая траектория потенциала сохраняет настоящий знак отклонения.

Для HS `d = R1 + R2`. Это радиус сферы исключения в относительной задаче. Нарисованная вокруг центра сфера радиуса d не обозначает радиус одной физической молекулы.

## Потенциалы

- HS: непроницаемое ядро `r < 1`, вне ядра `U = 0`.
- IPL: `U = r^(-n)`, изменяемый показатель n от 4 до 24.
- Сазерленд: непроницаемое ядро `r < 1`, вне ядра `U = −r^(-6)`.
- LJ: `U = 4(r^(-12) − r^(-6))`.
- Кулоновское отталкивание: `U = 1/r`.

В `potential(r,'sutherland')` хвост `−r^(-6)` технически продолжен внутрь ядра только для локализации события отражения. Это не разрешённая физическая область: решатель останавливается на `r=1` и отражает радиальную скорость. Не используйте это продолжение как физический потенциал внутри ядра. В графике внутренность ядра закрыта.

## Интегрирование

HS решается аналитически; нормальная составляющая скорости меняет знак, касательная сохраняется. В истории есть две записи в один момент времени по обе стороны мгновенного изменения скорости; при проигрывании импульс не растягивается интерполяцией.

Гладкие силы интегрируются методом Дормана–Принса 5(4). Локальная абсолютная добавка `1e-11`, относительный параметр по умолчанию `2e-9`; это параметры контроля шага, не апостериорная гарантия глобальной ошибки. На каждом принятом шаге контролируются энергия и момент количества движения. Для Сазерленда момент достижения ядра локализуется бисекцией; радиальная скорость отражается упруго.

E и b заданы на бесконечности. Начальные данные на конечной сфере сохраняют E и L, а ориентация входа и выходная асимптота исправлены интегралом дальнего хвоста. Состояния `step-limit`, `time-limit`, `step-underflow`, `numerical-failure` явно отличаются от `ok`.

График Θ(b) рассчитывается отдельно радиальным интегралом:

```text
Θ = π − 2 ∫[rmin,∞] b dr / (r² sqrt(1 − b²/r² − U(r)/E)).
```

Ветвь точки поворота выбирается снаружи внутрь: нужна первая доступная область `1 − b²/r² − U/E = 0`, а не произвольный корень. Стационарные точки включены в поиск, чтобы не пропустить узкий барьер. Корневая особенность квадратуры устраняется заменой `r = rmin/(1−t²)`. Для LJ около критического b добавляются узлы сгущения; критическая точка отмечается как особая, без выдуманного конечного угла.

## Сечения и статистика

Для монотонной ветви центрального рассеяния `dσ/dΩ = b/|sinχ| |db/dχ|`; для нескольких ветвей вклады суммируются. У HS `χ = 2acos(b/d)` и `dσ/dΩ = d²/4`.

Входная выборка: `b = d sqrt(U1)`, `φ = 2πU2`. Генератор детерминированный, seed сохраняется. Гистограмма строится в равных интервалах cosχ, имеющих одинаковый телесный угол. Штрихи на столбиках — приближённый счётный разброс `sqrt(Nk)`; не доверительный интервал при малых счётчиках и не оценка ошибки модели.

Для потенциалов угловая гистограмма сечения строится консервативным переносом площадей колец, с учётом разных ветвей. Внутри интервала выборка равномерна по b². Это конечные угловые интервалы и конечная сетка b, а не точечное разрешение сингулярности радуги/орбитирования. Пропущенная из-за нечисловых углов площадь возвращается как `omitted`. При бинировании её нельзя считать равной нулю.

На таком графике явно указан `b ≤ bmax`. Для бесконечного хвоста LJ/IPL/Coulomb площадь конечного пучка не выдаётся за полное геометрическое сечение взаимодействия. Численный срез по b не является физическим радиусом молекулы.

## HS / VHS / VSS

Модельные параметры нормированы при `gref = sqrt(2)`, `dref = 1`:

```text
dVHS(g)/dref = (gref/g)^(ω−1/2)
cos χVSS = 2(b/d)^(2/α) − 1
(dσ/dΩ)VSS = α d²/4 [(1+cosχ)/2]^(α−1).
```

При α=1 получается VHS; при ω=1/2 эффективный диаметр постоянен. Это нормированное семейство, не параметры конкретного газа и не полная Bird-конвенция для подбора dref по вязкости. Равенство диаметра dref при выбранной опорной скорости задано непосредственно. При фиксированном d изменение α сохраняет интегральное сечение πd². VHS/VSS не представлены как произвольные дополнительные функции U(r).

## Данные и управление

CSV: траектория с временем и инвариантами; функция отклонения с χ, Θ и статусом; ансамбль с b, φ, χ, cosχ, направлением, номером углового интервала и флагом поступления. Метаданные содержат параметры и seed. Время в потенциалах — приведённое физическое время; анимация переноса кольца и набора ансамбля иллюстрирует отображение мер, не время реального многомолекулярного опыта.

`chapters.js` содержит учебный сценарий. Его можно менять без изменения физики. В `app.js` находятся UI, кэширование, графики и сцены. `physics.js` не зависит от DOM. `window.collisionLab` — интерфейс для локальной проверки: `getState`, `getDiagnostics`, `go`, `set`, `redraw`.

## Первичные источники и проверочные формулы

1. TU Delft, Mechanics and Relativity, **Scattering**: https://qiweb.tudelft.nl/mecharela/scattering/ — кольцо входных параметров, телесный угол, якобиан сечения, кулоновское рассеяние. В используемых единицах проверяется `χ = 2atan(1/(2Eb))`.
2. SPARTA, **collide command**: https://sparta.github.io/doc/collide.html — параметры VHS/VSS, смысл α и ω, переход α=1 к VHS. Документация также указывает Bird (1994), §§2.6–2.7, и Koura & Matsumoto (1992).
3. G. A. Bird, **Molecular Gas Dynamics and the Direct Simulation of Gas Flows**, Oxford, 1994 — библиографическая основа моделей столкновения, не заимствованный исходный код.

Проверка траекторий: аналитические HS/Rutherford, независимая радиальная квадратура, сохранение энергии и момента. Код и объяснения здесь оригинальные; код PhET, SPARTA или чужих демонстраций не встроен.

## Ограничения поставки

Текущий репозиторий Chalkish был недоступен при подготовке. Новый 3D-модуль аддитивен и не использует неизвестный старый 2D API. Это Canvas2D-проекция настоящей пространственной геометрии с сортировкой по глубине; ограничения прозрачных пересекающихся поверхностей изложены в `lib/chalkish/COLLISION_3D.md`.

Приложение описывает упругие центральные столкновения без вращательного/колебательного обмена, химии и квантовых эффектов. Показ конкретного орбитирования не равносилен проверке всех околокритических параметров. Использование для количественной публикации требует дополнительного исследования сходимости по шагу, радиальной квадратуре, сетке b и угловым интервалам.
